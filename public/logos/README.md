# Funding logos

Put the official Interreg logo here as `interreg.svg` (or `.png`, then change the file name in
`src/components/FundingLogos.tsx`). Use the files supplied by the project's communication team
(Julia Walter); the programme's visual identity rules say how the logo must be shown (size, clear
space, no changes). Until the file exists, the app shows a text line instead.
